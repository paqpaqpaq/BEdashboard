# Balansenergie All-in — v4.6.5

## Nieuw in deze versie

- EPEX day-ahead is geïntegreerd en aan/uit te zetten bij de tariefgrafiek.
- De legenda staat links boven de grafiek, uitgelijnd met de y-as. De compacte EPEX-toggle staat rechts op dezelfde regel.
- EPEX volgt de All-in-instelling, inclusief btw, energiebelasting en eenmaal 2 cent opslag per kWh.
- De gekozen EPEX-stand wordt onthouden.

**Schakel na deze update de losse EPEX-plugin uit en herlaad het dashboard.**

## Installeren

- **Safari / Tampermonkey:** [installeer het userscript](https://raw.githubusercontent.com/paqpaqpaq/BEdashboard/main/Balansenergie-All-in.user.js).
- **Chrome-extensie:** [download v4.6.5](https://github.com/paqpaqpaq/BEdashboard/raw/refs/heads/main/BE_dashboard_4_6_5.zip), pak uit en laad de map via `chrome://extensions` → **Ontwikkelaarsmodus** → **Uitgepakte extensie laden**.
